# 觀測器增益公式總結

## 目標

將**所有觀測器極點配置在 λₑ**

## 3×3 矩陣（控制器1）

### 完整公式

#### ℓ₁
```
ℓ₁ = 1 + β + λc - 3λₑ
```

#### ℓ₂
```
ℓ₂ = [b(bβ² - 3bβλₑ + bβ + 3bλₑ² - 3bλₑ + b + β² - 3βλₑ + β + λₑ³)
      - (b² + bβ + b + β)(β² - 3βλₑ + β + 3λₑ² - 3λₑ + 1)]
     / [kc(b + 1)(b + β)]
```

#### ℓ₃
```
ℓ₃ = [-bβ² + 3bβλₑ - bβ - 3bλₑ² + 3bλₑ - b - β² + 3βλₑ - β - λₑ³]
     / [kc(b + 1)(b + β)]
```

### 簡化形式（β = 0）

當 **β = 0** 時，公式大幅簡化：

#### ℓ₁
```
ℓ₁ = 1 + λc - 3λₑ
```

#### ℓ₂
```
ℓ₂ = (λₑ - 1)³ / [kc(b + 1)]
```

#### ℓ₃
```
ℓ₃ = [-3bλₑ² + 3bλₑ - b - λₑ³] / [bkc(b + 1)]
```

**關鍵發現**：
- **ℓ₂ = (λₑ - 1)³ / [kc(b + 1)]** 與 4×4 的模式一致！

### LaTeX 格式

```latex
\ell_1 = 1 + \beta + \lambda_c - 3\lambda_e

\ell_2 = \frac{b(b\beta^2 - 3b\beta\lambda_e + b\beta + 3b\lambda_e^2 - 3b\lambda_e + b + \beta^2 - 3\beta\lambda_e + \beta + \lambda_e^3) - (b^2 + b\beta + b + \beta)(\beta^2 - 3\beta\lambda_e + \beta + 3\lambda_e^2 - 3\lambda_e + 1)}{k_c(b + 1)(b + \beta)}

\ell_3 = \frac{-b\beta^2 + 3b\beta\lambda_e - b\beta - 3b\lambda_e^2 + 3b\lambda_e - b - \beta^2 + 3\beta\lambda_e - \beta - \lambda_e^3}{k_c(b + 1)(b + \beta)}
```

**當 β = 0**：

```latex
\ell_1 = 1 + \lambda_c - 3\lambda_e

\ell_2 = \frac{(\lambda_e - 1)^3}{k_c(b + 1)}

\ell_3 = \frac{-3b\lambda_e^2 + 3b\lambda_e - b - \lambda_e^3}{bk_c(b + 1)}
```


#### ℓ₃
```
ℓ₃ = -(λₑ - 1)⁴ / [(b + 1)kc]
```

#### ℓ₄
```
ℓ₄ = [λₑ⁴ + 4bλₑ³ + 6b²λₑ² - 4b(2b + 1)λₑ + 3b² + 2b] / [(b + 1)²bkc]
```

### LaTeX 格式

```latex
\ell_1 = 2 + \lambda_c - 4\lambda_e

\ell_2 = \frac{(\lambda_e - 1)^3(4b + \lambda_c + 3)}{(b + 1)^2 k_c}

\ell_3 = \frac{-(\lambda_e - 1)^4}{(b + 1)k_c}

\ell_4 = \frac{\lambda_e^4 + 4b\lambda_e^3 + 6b^2\lambda_e^2 - 4b(2b + 1)\lambda_e + 3b^2 + 2b}{(b + 1)^2 b k_c}
```

## 模式比較

### ℓ₁ 的模式

| 矩陣 | ℓ₁ 公式 | 極點數 |
|------|---------|--------|
| 3×3 | **1** + β + λc - **3**λₑ | **3** 個極點 |
| 4×4 | **2** + λc - **4**λₑ | **4** 個極點 |

**規律**：`ℓ₁ = (n-2) + ... + λc - n·λₑ`，其中 n 是矩陣維度

### ℓ₂ 的模式（β = 0 時）

| 矩陣 | ℓ₂ 公式 | 分母中 (b+1) 的次方 |
|------|---------|---------------------|
| 3×3 | **(λₑ - 1)³** / [kc(b + 1)¹] | 1 |
| 4×4 | **(λₑ - 1)³**(4b + λc + 3) / [kc(b + 1)²] | 2 |

**關鍵**：都包含 **(λₑ - 1)³** 項！

### ℓ₃ 的模式

| 矩陣 | ℓ₃ 公式 | 主要項 |
|------|---------|--------|
| 3×3 (β=0) | 複雜表達式 / [bkc(b + 1)] | 包含 λₑ³ |
| 4×4 | **-(λₑ - 1)⁴** / [kc(b + 1)] | **(λₑ - 1)⁴** |
